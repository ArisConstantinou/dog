# Leo 3D model sources

- Primary interactive rig: **Dog - Jack Russell Terrier** by RedDeer, embedded through the public Sketchfab Viewer API. The model stays hosted by Sketchfab and is not redistributed in this repository: https://sketchfab.com/3d-models/e75a550f4a9b4d18bc1b45ca2e6f56d2
- Local continuity fallback: **Animated Animales Low Poly / Animal Pack Vol. 2** by Quaternius, CC0. The included dog FBX was converted to glTF for browser playback: https://opengameart.org/content/animated-animales-low-poly

The Sketchfab rig supplies the full-body mesh, skeleton, and action animation library. The CC0 fallback is intentionally only used if the network viewer cannot initialize.
